Normal activation flow:
1. User enters Latin first/last name and courier ID.
2. User enters a KX key generated by OWNER.
3. The key is atomically changed UNUSED -> USED and bound to one Firebase UID/device.
4. The profile appears automatically in KurierX Control.
5. Route/OCR/statistics data remain local on the phone.

OWNER flow:

- More -> KurierX Control.
- Create keys, edit users, freeze/unfreeze, blacklist/unblacklist, delete users/licenses.

Remote state is listened to in realtime when the phone has Internet. If the phone is offline, the last valid local profile is used until Firebase can be reached again.
